UKG Calendar Downloader

View Project on GitHub

A useful tool that reads information from UKG, and converts it into a downloadable file for importing to Google Calendar.

This browser extension adds the ability to export a copy of your monthly calendar from UKG. I prefer to keep all of my events in one place, and since UKG doesn't offer a convenient way to automatically add shifts to Google Calendar, I decided to create a way myself.

The extension pulls information about your shifts from the webpage, then uses it to create an ICS (Internet Calendaring and Scheduling) file, which is automatically downloaded to the computer and ready to be imported into any compatible calendar.

CrossCode Save File Descriptions

View Project on GitHub

A simple mod that allows the creation, saving, and display of short descriptions to differentiate save files in the indie game CrossCode.

This mod is a small, quality-of-life tweak to one of my favorite indie games. After creating several save files, I noticed an issue - that keeping track of them could be difficult, as they all appeared largely the same on the file select screen.

I decided to take matters into my own hands and create a mod to fix it. I made use of an already-existing text display on the screen to show a short, customizable description of the user's save files.
